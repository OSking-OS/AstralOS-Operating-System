# Astral OS

An experimental operating system project.

## About

Astral OS is a personal project focused on operating system development, booting, and low-level programming.

## Current Status

* Experimental ISO available
* Boot issues under investigation
* Development in progress

## How to Test

Use a virtual machine such as QEMU or VirtualBox to test the ISO. Boot compatibility is not guaranteed.

## Disclaimer

This is an experimental project and is not intended for production use.
